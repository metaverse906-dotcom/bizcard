隱私權政策

隨身名片夾・生效日期：2026 年 10 月 17 日

一句話說完

隨身名片夾沒有伺服器，不收集、不保存、也看不到你的任何資料。你的名片只存在你的手機裡；如果你選擇備份，就存在你自己的 Google Drive。

資料存在哪裡

  • 你的名片、收到的名片、照片、備註和設定，都存在這支手機的瀏覽器儲存空間裡，不會上傳到開發者或任何第三方。
  • 本 app 沒有帳號系統、沒有分析或追蹤工具、沒有廣告。
  • 名片照片的文字辨識在手機上進行，照片不會上傳。

Google 使用者資料（雲端備份）

只有在你按下「備份到 Google Drive」或「從 Google Drive 還原」時，本 app 才會請你登入 Google 並授權。

  • 申請的權限：只有 drive.file。這個權限只能存取本 app 自己建立的檔案，看不到、也改不了你 Google Drive 裡的其他檔案。
  • 用途：在你的 Google Drive 建立、更新與讀取一個名為「名片夾備份.json」的備份檔，內容是你在本 app 裡的資料。除此之外不做任何其他用途。
  • 不會被保存或分享：授權憑證只暫存在當下開啟的頁面記憶體中，關閉 app 就消失；備份內容直接在你的手機和你的 Google Drive 之間傳送，不經過開發者，也不會提供給任何第三方。
  • 符合 Google 政策：本 app 使用從 Google API 取得的資訊，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。
  • 隨時可以取消：到 Google 帳戶的「第三方應用程式和服務」移除本 app 的存取權；備份檔可以直接在 Google Drive 刪除。

電子名片與分享

  • 電子名片的內容放在連結網址「#」後面的部分，瀏覽器不會把這部分傳給網站伺服器。
  • 拿到連結或掃到 QR code 的人都看得到上面的內容。名片上要顯示哪些資料，由你在設定裡決定。
  • 對方按「存成圖片」或「加入聯絡人」時，檔案只存在對方自己的手機。

本 app 使用的外部服務

載入網頁、字體和程式時，以下服務會收到一般的連線資訊（例如 IP 位址、瀏覽器類型），這是任何網站都會有的；本 app 不會額外傳送你的名片資料給它們：

  • GitHub Pages：網站託管
  • Google Fonts：中文字體
  • cdnjs、jsDelivr：QR code 元件、文字辨識引擎
  • Google 登入與 Google Drive：只在你使用雲端備份時

刪除你的資料

  • 刪除單張名片：在名片詳情按「刪除這張」。
  • 全部刪除：在手機瀏覽器的網站設定裡清除本網站的資料，或移除已安裝的 app。
  • 雲端備份：在 Google Drive 刪除「名片夾備份.json」。

政策變更與聯絡方式

本政策如有修改，會更新本頁上方的生效日期。有任何問題，可以在本專案的 GitHub 頁面留言。

Privacy Policy (English summary)

隨身名片夾 (Pocket Card Holder) has no server and does not collect, store, or have access to any user data. All cards, photos and settings are stored only in the browser storage on the user's own device. There are no accounts, analytics, trackers or ads. Text recognition runs on the device; photos are never uploaded.

Google user data. Only when the user taps "Back up to Google Drive" or "Restore from Google Drive", the app requests the drive.file scope, which only allows access to files created by this app. It is used solely to create, update and read a single backup file ("名片夾備份.json") in the user's own Google Drive. The access token is kept in memory only for the current session and is never sent to the developer or any third party. The backup data travels directly between the user's device and the user's Google Drive. This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time at Google Account › Third-party apps & services.

Contact: GitHub issues. Effective date: 17 October 2026.
