# 隨身名片夾

自己用的數位名片與名片夾，可以安裝到手機桌面。

- **我的名片**：對方用相機掃 QR code（vCard 格式）就能存進聯絡人；「遞名片」畫面會把名片轉向坐在對面的人。
- **名片夾**：收到的名片疊成一盒，可附名片照片、記下在哪裡認識。
- **個人化**：主題顏色、四組字體、名片上要顯示哪些資料。
- **隱私**：所有資料只存在你自己手機的瀏覽器（IndexedDB），沒有伺服器、沒有帳號。備份是你自己匯出的檔案。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 app |
| `manifest.webmanifest` | 讓手機能「安裝」成 app |
| `sw.js` | 離線快取，沒網路也能打開 |
| `icon-*.png`、`apple-touch-icon.png` | 圖示 |

## 改版時

1. 修改 `index.html`。
2. 把 `sw.js` 第一行附近的 `CACHE = "bizcard-v1"` 版本號加一（例如 `v2`），手機才會換成新版。
3. 上傳覆蓋舊檔。

打賞連結在 `index.html` 裡的 `TIP_URL`，填上網址就會啟用。
